# UI 行为约束：侧栏与用户脚本

## 1. 侧栏形态

断点 **600dp**，两套形态互斥：

| 窗口宽度 | 形态 | 行为 |
|---|---|---|
| < 600dp | 底部抽屉 | peek / 展开（约 65%）/ 全高（约 90%）；可拖拽；键盘弹出时避让 |
| ≥ 600dp | 并排 | 右侧面板，可拖拽调宽；页面不被遮挡 |

约束：

- 面板内 `window.innerWidth` 必须反映**容器**宽度（扩展按宽度做响应式）。
- 关闭侧栏不销毁扩展宿主（`localStorage`、表单状态保留）。
- 跨 600dp 断点（旋转 / 桌面模式改尺寸）自动关闭面板，重新打开按新形态呈现——
  禁止两套布局同时存在。
- 窄屏宿主挂在 Activity 内容视图时，关闭必须从**当前父容器** detach（补丁 0011）。
- 隐藏侧栏 UI（如进入标签页切换器）时同步隐藏抽屉，避免浮层遮挡。

## 2. 用户脚本（`chrome.userScripts`）

- 默认允许（补丁 0008）：扩展仍须声明 `userScripts` 权限；扩展详情页保留「允许运行用户脚本」开关。
- 开关关闭时，API 返回明确错误，不得静默失败。
- 用户脚本以 `USER_SCRIPT` 世界执行；需要页面世界的脚本用 `world: 'MAIN'`。

## 3. 入口

- 扩展 action 点击：扩展声明 `side_panel.default_path` 且 `getOptions().enabled` 时打开面板。
- 扩展菜单（`ExtensionsMenuCoordinator`）为有面板的扩展提供「打开侧栏」。
- 记住最近一次打开的面板（per-tab）。
- 手机工具栏暂不内联固定 action 图标；动作走扩展菜单，popup 使用扩展容器作为锚点（补丁 0002 / 0009）。

## 4. 与内核补丁的对应

| 行为 | 补丁 |
|---|---|
| 手机工具栏扩展承载点 | 0002 |
| popup 容器锚点回退 | 0009 |
| 窄屏抽屉 / 宽屏并排 + 断点切换 | 0010 |
| 关闭时从当前父容器 detach | 0011 |
